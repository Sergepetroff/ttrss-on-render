# ttrss-on-render

## Быстрый деплой TT-RSS на Render (бесплатно)

1. Создай репозиторий на GitHub и залей все файлы из этого архива.
2. Перейди на https://render.com -> New -> Web Service -> выбери этот репозиторий.
3. Render сам создаст контейнер и базу Postgres (free tier).
4. После деплоя TT-RSS будет доступен по адресу https://<имя>.onrender.com
5. Логин: admin / admin123
6. Обновление фидов каждые 2 часа (через cron внутри контейнера).
7. Плагин af_feedmod (фулл RSS) уже активирован в plugins.local/.

Если Render "спит" из-за неактивности, фиды обновятся при первом запросе.
